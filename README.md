# Merchant League

A slow-turn multiplayer trading game played on the XRP Ledger **Testnet**.

**Status: design stage.** Nothing is playable yet. Testnet only: no real money, no Mainnet path.

The XRPL Testnet is wiped from time to time (next on 2026-11-25), which deletes every account and transaction on it. The live checks in [`docs/receipts/`](docs/receipts/) were taken before that reset, so their hashes stop resolving afterwards; what they recorded, and the test vectors, stay the evidence.

The design is under research before the rules are built. See the CHANGELOG for progress.

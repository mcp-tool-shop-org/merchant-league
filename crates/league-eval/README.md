# `league-eval`

Merchant League Evaluation Mode harness, frozen-state branch runner, deterministic state selector, and S3a/S3b unblinded decision-scorer pipeline (see [docs/eval-harness.md](../../docs/eval-harness.md) and [docs/decision-scorer.md](../../docs/decision-scorer.md)).

## Subcommands

- **`play`:** Play up to `--turns` full turns from standard setup or turn-0 fork under `--arm <off|control|on>` and `--communication <talk|silent>` (under `silent`, removed communication keys sent even as `null` still refuse the act reply and preview/draft tool call), supporting `"ClubBot"`, `"random-legal"`, `"always-defect"`, and `"tit-for-tat"` (`talk`-only, refused under `silent` with `BASELINE_REQUIRES_TALK`) `"file"` policies and saving pre-act checkpoints and recorded act submissions.
- **`branch`:** Replay a frozen pre-act checkpoint across `--arms <off,control,on>` and `--communication <talk|silent>` holding peer actions fixed (`COMMUNICATION_CONDITION_MISMATCH` if the source checkpoint condition disagrees).
- **`select`:** Deterministically select stratified early/mid/late pre-act checkpoints across games.
- **`build-blind-inputs`:** Scan homogeneous `--run <dir>...` directories (`MIXED_COMMUNICATION_CONDITIONS` if `talk` and `silent` inputs mix; under `silent`, skips talk/negotiation extraction cleanly with zero counts) (`decision.json`, `outcome.json`, `manifest.json`, `setup.json`, `to-seat/*.negotiation.json`, `decisions/day-DD-talk-*.json`, and `relay/seats/*.tool-round-*.json`), parse committed decisions (`parse_eval_act_reply_for_communication`), recover first sent valid tool drafts in `(round_index, attempt, call_index)` order using the recorded `call.call_index` field, extract closed-grammar deterministic `talk_rules_v2` peer trade commitments (normalizing listed typographic apostrophes, rejecting unlisted ASCII/non-ASCII bytes including `"` and `?`, restricting colon-space lead-ins to `colon_space_lead_templates`, parsing whole numbers or exact `1,000`-style thousands comma groups scaled to `league_seat_types::UNIT_SCALE` milli-units/milli-`CRED`, accepting only `@`/`at` unit price cues, and matching whole clauses against the 25-field `TalkRulesV2Table` while failing closed per message with pair latching on any unlisted clause and retraction/latch-dominant cross-source merging) plus required per-source and total `talk_extraction_counts` (`seen`, `matched`, `ambiguous`), merge with `league-scorer` arm-independent candidates by canonical `candidate_id` with OR-merged flags, and write disjoint `--out-blind` (`BlindScoringRequest` v1 without paths, timestamps, arms, wording labels, or tool traces, covering `talk_extraction_counts` under `blind_request_sha256`) and `--out-arm-map` (`ArmMapStateFile`). Optionally pass `--out-checkpoints <dir>` to populate content-addressed `.save.json` / `.seal` blobs.
- **`verify-checkpoints`:** Replay every Evaluation Mode pre-act checkpoint inside `--checkpoints <dir>` (`<stem>.save.json` / `<stem>.seal` or content-addressed `<64-hex>.save.json` / `<64-hex>.seal`) from Turn 0 in the current engine build (`EvalHost::verify_checkpoint_causal_raw`, format `v2` only; `v1` refused everywhere with `INCOMPATIBLE_ENGINE_OR_SCHEMA_VERSION` and no legacy flag), verifying strict duplicate/unknown-key JSON decoding, canonical byte round-trip equality, domain-separated `save_sha256`, per-turn VRF proofs/shocks/digests, tip equivalence, `seat_count == 4` (`INVALID_EVAL_SEAT_COUNT`), and a 1-turn deterministic `ClubBot` probe step; optionally validate complete coverage against `--blind <dir>`, require a valid non-empty 40-hex `LEAGUE_EVAL_GIT_SHA`, mark verified checkpoint files read-only, and write write-once read-only `--out <verified_checkpoints.json>` recording `engine_build_id` and per-checkpoint `engine_commit` provenance (see [`docs/checkpoint-trust.md`](../../docs/checkpoint-trust.md)).
- **`freeze`:** Refuse dirty git worktrees (`DIRTY_GIT_WORKTREE`), existing target files (`FREEZE_FILE_EXISTS` via atomic `create_new`, removing the partial file if writing fails and reporting any cleanup failure), mixed `talk`/`silent` inputs across optional `--arm-map` / `--run` provenance (`MIXED_COMMUNICATION_CONDITIONS`), and omitted/missing `--verified-checkpoints <file>` (`MISSING_VERIFIED_CHECKPOINTS`, checking `engine_build_id == scorer_git_sha` and complete coverage of `--blind` inputs with `VERIFIED_CHECKPOINTS_MISMATCH`), validate blind inputs and `ScorerConfig`, compute canonical POSIX-path `scorer_tree_sha256` across `crates/league-scorer/**`, and write write-once `scorer_freeze.json` with `scorer_git_sha`, `scorer_tree_sha256`, `scorer_config_sha256`, `control_wording_arm`, `talk_extractor_version`, `talk_extractor_rules_digest`, `blind_inputs_manifest_sha256`, and `verified_checkpoints_sha256`. Running `league-scorer score --freeze <file>` likewise requires `--verified-checkpoints <file>`.
- **`join`:** Fail closed on missing freeze files (`MISSING_FREEZE_FILE`), missing/omitted `--verified-checkpoints <file>` or missing `scorer_freeze.json::verified_checkpoints_sha256` (`MISSING_VERIFIED_CHECKPOINTS`), verified-manifest mismatches (`VERIFIED_CHECKPOINTS_MISMATCH`), duplicate `state_id` entries across `--arm-map` or `--scores` files (`DUPLICATE_STATE_ID`), blind-input manifest mismatches (`FREEZE_MANIFEST_MISMATCH`, verified directly against each scored file's echoed `blind_request_sha256` even when `--blind` is omitted), config hash mismatches (`FREEZE_CONFIG_MISMATCH`), `control` wording-arm mismatches (`CONTROL_WORDING_ARM_MISMATCH` on `setup.json` / `manifest.json` / `relay/setup.json`), or mixed `talk`/`silent` inputs (`MIXED_COMMUNICATION_CONDITIONS`), then join `scores/*.json` with `arm_map/` by `(state_id, candidate_id)` into descriptive-only `joined_decisions.json` and `per_arm_summary.json` tables (recording top-level `verified_checkpoints_sha256`, `scorer_engine_build_id`, `checkpoint_engine_commits`, and `scenario_randomness_scope`, per-row `checkpoint_engine_commit`, descriptive per-arm `talk_counts` totals and per-state distributions, §7.2 `DecisionMechanismMetrics` and `PerArmMechanismSummary` diagnostics for tool-call rate, draft-to-commit revision gain, single-pass in-memory reasoning length + `completion_tokens`/`reply_token_ids` length companions, illegal-order rate, engine-recorded pledges/`broken_promises`, and optional `--source-game <dir>` repeatable inputs for outgoing `talk_rules_v2` deal-keeping `honoured_commitments / applicable_commitments` with fixed `per_arm_summary.json::data_limits`; missing or unparseable optional sidecars emit `null` and count in `unparseable_sidecars` / `n_unparseable_sidecars` without aborting the join report, and zero prose leaves memory).

## Boundary With `league-scorer`

`league-eval` depends on [`league-scorer`](../league-scorer/README.md) to generate arm-independent candidates and compute canonical digests, while `league-scorer` has zero compile-time or runtime dependency on `league-eval` or `league-relay`. Only `league-eval` handles arm labels, `arm_map/`, wording labels, tool sidecars, and whisper prose.

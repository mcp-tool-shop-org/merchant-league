## 0. Scope, Premise Corrections, and Epistemic Rules

Under the `2026-11-17` scope ruling recorded in `#68` and [`docs/design-v2.md`](design-v2.md#L5), `v0.1.0` is **Club Mode**—an offline terminal season in `league-tui` over pure-Rust `league-core` with humans on one machine and simple rule-based bot seats, playing a season in roughly `90 minutes` `[target]` at `3–5 minutes` `[target]` a turn—and every `2026-11-17` design-review improvement tracked in `#68` lands before `1.0` in an order paced by the Publisher.

Three rules govern every figure and citation in this document:

1. **No simulated or newly computed figures:** Every quantitative value either cites its source (`path:line` at `ed872e53bc9381ac2e2f76167164173b113788f2` or named report file) or is explicitly marked `[target]`.
2. **Unchecked external citations:** External academic or industry studies referenced through deep-research reports (seeds `25–33`) have **not** been audited at primary source here and are marked `(unchecked at source, via <report>)` whenever a design choice relies on them.
3. **Four premise corrections applied (`2026-11-17-rnd-premise-check-ml-design-advice.md`):**
   - *Preview vs. static predicates:* `crates/league-core/src/predicates.rs:1-20` (`compute_seat_state_predicates` at `predicates.rs:625-642`) computes static start-of-turn diagnostics (*if nothing changes before Sweep*). It does not simulate hypothetical bundles; [`TurnEngine::preview_bundle`](../crates/league-core/src/engine.rs#L904-L912) and [`TurnEngine::preview_bundle_with_context`](../crates/league-core/src/engine.rs#L916-L1047) already clone `TurnEngine` and execute the real Sweep path. The What-If Preview (§2) composes **both** rather than building a second rules engine.
   - *Currency codes already draw from a 61-word English glossary:* [`ALLOWED_COMMODITY_GLOSSARY`](../crates/league-gen/src/schema.rs#L540-L602) already restricts generated 3-letter codes to `61` curated trade nouns (`ALM` = `"alum"`, `TMB` = `"timber"`) while rejecting uncurated strings such as `QZX` (`schema.rs:688-706`) and `521` denied ISO/crypto/reserved tickers (`DENIED_CURRENCY_CODES`, `schema.rs:624-677`). Each table samples `2 * N` distinct codes (`8`, `10`, or `12` goods for `N in 4..=6` seats at `crates/league-gen/src/generator.rs:452, 563-570`) rather than a single paired raw/refined chain.
   - *Variable season horizon:* Seasons run `24..=32` turns (`CLOSING_ROLL_START_TURN = 24`, `HARD_TURN_CAP = 32`, `DEFAULT_CLOSING_HAZARD_BPS = [3_500; 8]`, expected length `25.80` turns and `3.19%` Turn-32 probability per [`types.rs`](../crates/league-core/src/types.rs#L62-L75) and [`docs/design-v2.md`](design-v2.md#L242-L245)). Thus `~90 minutes` `[target]` is an expected-duration target at `~3.5 min/turn` (`210 s` `[target]`), not a hard wall-clock bound across `32 * 5 min = 160 min` without early commit advance.
   - *Benchmark comparability for AI preview:* Granting AI seats exact pre-commit simulation alters what automated Evaluation Mode measures (compressing arithmetic-error variance and shifting invalid-transaction / stability metrics in [`docs/design-v2.md`](design-v2.md#L310)), so AI access to the tool must be gated behind an explicit relay/Eval flag and named wording arm (§8).

## 1. Full Offline Season Loop in `league-tui` over `league-core`

### 1.1 Starting Point at `ed872e53`

At `ed872e53`, [`crates/league-tui/Cargo.toml`](../crates/league-tui/Cargo.toml#L1-L16) is a library-only stub depending solely on `ratatui = "0.30.2"` and `crossterm = "0.29.0"` (`Cargo.toml:23-26`), with no `[[bin]]` target, no `league-core` or `league-gen` dependency, and a three-line placeholder screen ([`TITLE_LINES`](../crates/league-tui/src/lib.rs#L14-L18), [`Action`](../crates/league-tui/src/lib.rs#L22-L27), [`draw_title`](../crates/league-tui/src/lib.rs#L39-L51)). Meanwhile, `league-core` already provides a zero-I/O, zero-ledger deterministic engine ([`TurnEngine`](../crates/league-core/src/engine.rs#L446-L448)) executing all `9` deterministic Sweep stages (Step `0` plus Steps `1–8`, `engine.rs:1188-1278`). Club Mode pairs `league-tui` directly with `league-core` and `league-gen` with zero `xrpld`, zero Testnet socket calls, and zero model API calls.

### 1.2 Lobby Bootstrap, Pacing Target, and Seed Hygiene

Launching the `league-tui` binary opens `crossterm` raw mode and `EnterAlternateScreen` (with a panic and signal guard restoring cooked mode before writing any error to `stderr`). From the Lobby screen, players configure:

- **Table composition (`N in 4..=6`):** Seat count `4`, `5`, or `6` (`TableSpec::validate` at [`types.rs`](../crates/league-core/src/types.rs#L616-L622)), assigning each seat `0..N` to either `Human` (local hot-seat player, optional 4-digit table-local PIN) or `ClubBot` (deterministic rules-only opponent tagged `SeatIdentity::AiSyndicate` at [`types.rs`](../crates/league-core/src/types.rs#L411-L416), preserving upfront AI disclosure from [`docs/design-v2.md`](design-v2.md#L270)).
- **Seed selection strictly in `SeedPool::Dev` (`0..=9_999`):** Calling `is_reserved_test_seed(seed)` ([`schema.rs`](../crates/league-gen/src/schema.rs#L146-L155)) and `generate_ring_table_for_setup(seed, TableSetupOptions { purpose: TablePurpose::Dev, training_logged: false }, &config)` ([`generator.rs`](../crates/league-gen/src/generator.rs#L237-L263)). Any `train` (`10_000..=999_999`), `probe` (`1_000_000..=1_099_999`), `held_out` (`2_000_000..=2_099_999`), `sealed` (`>= 2^63`), or `unassigned` seed (`schema.rs:34-71, 95-101`) is refused with exit `1` (`SEED_POOL_MISMATCH` / `RESERVED_SEED_FORBIDDEN`).
- **Turn clock presets targeting `~90 minutes` at `3–5 minutes/turn`:** Default turn budget is **`210 s` (`3m30s`) `[target]`** (configurable across `180 s..=300 s` `[target]`, matching the `3–5 min` Club Mode target in `#68`, or toggled to **Untimed Hot-Seat** for teaching games). At the expected `25.80`-turn duration (`types.rs:71-75`, `docs/design-v2.md:244`), `210 s` `[target]` per turn gives a `~90.3 min` `[target]` ceiling even before early advances when all human seats lock commits. Inside each timed turn, `75%` of the clock runs open `TalkAndMarket` and the final `25%` (`DEFAULT_CANCEL_LOCK_BPS = 2_500`, [`types.rs`](../crates/league-core/src/types.rs#L149)) engages `TurnEngine::begin_cancel_lock()` (`engine.rs:602-612`).
- **Offline CSPRNG deals and turn beacons:** Turn-1 mandates deal via `deal_graded_mandates` ([`commit.rs`](../crates/league-core/src/commit.rs#L628-L640)) using OS CSPRNG entropy (`getrandom`), and the local host generates an independent `SealedEvalSeed::generate()` (`commit.rs:1279-1281`) whose `public_key_bytes()` (`commit.rs:1296-1299`) sets `TableSpec.eval_vrf_pubkey` under `TableMode::Eval` (`types.rs:541-549`). Neither entropy source is ever derived from the layout `seed` (checked by `SeasonReplayLog::from_rig_seed` at [`replay.rs`](../crates/league-core/src/replay.rs#L613-L643)).

### 1.3 Turn Structure on Screen

Each turn renders inside a structured four-zone `ratatui` layout (designed for `100x30` `[target]`, with stacked fallback to `80x24` `[target]`):

1. **Header Bar:** Current turn (`Turn t`), active `TurnPhase` (`TalkAndMarket`, `Commit`, `Reveal`), closing-window warning (`35.00%` per-turn hazard active once `t >= 24`, `types.rs:63-75`), active sub-turn timer, `[CANCEL LOCKED]` indicator from [`predicates::cancel_locked`](../crates/league-core/src/predicates.rs#L220-L222), active `Human` vs `ClubBot` seat banner, current `trade_minister` / `cartel_chair` badges (`engine.rs:128-132`), and active realized shocks / public `ShockForecastEvent`s (`engine.rs:158-159, 217-220`).
2. **Left Public Table & Ledger Mirror Pane:** Every seat's public [`SeatState`](../crates/league-core/src/engine.rs#L81-L117) (`cred`, `cred_debt`, `credit_tier`, free `raw`/`refined` balances, `project_equity`, tariffs, defaults/breaches, freeze turn), open and cartel [`CredOffer`](../crates/league-core/src/contracts.rs#L190-L211) order books, active `CreditCheck`s, `TokenEscrowVault`s, `DualEscrowVault`s, `IntentPledge`s, `CartelDomain`s, `CouncilPlatform`s, and rotating `ActiveCharter`s (`engine.rs:139-157`). Commodities display their in-world guild name alongside their `[CODE]` (§3).
3. **Center Action & Order Composer Tabs:**
   - *Tab 1 — Market & Contracts (`TurnPhase::TalkAndMarket`):* Dispatch `MarketAction` variants (`contracts.rs:282-358`): `PostOffer`, `CancelOffer` (blocked once `cancel_locked == true`, `engine.rs:634-636`), `CreateCheck`, `CancelCheck`, `CreateEscrow`, `CancelExpiredEscrow`, `RecordIntentPledge`, `StandForOffice`, `FlagWashFreeze` (`CustomsInspector` charter only, posting `wash_freeze_bond_cred = 500`, `types.rs:160`), and `TownImport` (`2.25x` parity fallback, `types.rs:137`).
   - *Tab 2 — Workshop, Deals & Politics (`SealedOrderBundle` Draft, [`commit.rs`](../crates/league-core/src/commit.rs#L248-L271)):* Compose `converter_runs`, `project_deliveries`, `atomic_swaps`, `dual_escrows`, `contract_deliveries`, `escrow_finishes`, `check_cashes`, `debt_repayment_cred`, Turn-`4n` `council_vote`, and Turn-`6n` `charter_bids`.
   - *Tab 3 — What-If Sandbox (`p`):* Runs `preview_what_if` (§2) live against `PublicPreviewState` with selectable counterparty assumption toggles before locking any commit.
   - *Tab 4 — Diplomatic Desk:* Send local seat-to-seat whispers (`<= 120` words `[target]`, matching `MAX_WHISPER_WORDS = 120` at [`wording.rs`](../crates/league-relay/src/wording.rs#L20)) and anchor matching `IntentPledge` headers (`commit.rs:312-326`).
4. **Right Seat Diagnostics & Private Vault Drawer:** Renders strictly for the active seat (hidden behind the curtain during hand-offs): own [`PrivateMandate`](../crates/league-core/src/commit.rs#L404-L409) (`MandateKind` objective + `3–8` points), own `OracleAuditor` Turn-`t` private shock hint via [`TurnEngine::private_hints_for_auditor`](../crates/league-core/src/engine.rs#L545-L562), and factual numeric gauges read from [`SeatStatePredicates`](../crates/league-core/src/predicates.rs#L191-L216) (`UpkeepAndDebt`, `SpoilageAndConversion`, `GoodScarcity`, `CoalitionReach`, and current `HoldingMark` floor split in `SeasonEndAndMarks`).

After every Sweep (`TurnEngine::sweep_turn_with_eval_vrf`, `engine.rs:1090-1095`), a **Sweep Chronicle Modal** summarizes [`SweepReceipt`](../crates/league-core/src/engine.rs#L229-L301): Step-0 batch fills, Step-2 swap/escrow/bond/converter resolutions, Step-3 cashed/bounced checks and `FlagWashFreeze` settlements, Step-4 projects and any C1a takeover conversions, Step-5 upkeep/debt accrual, Step-6 spoilage clawed back, Step-7 elections/charters/broken promises, newly forecast public shocks, and whether the closing bell rang (`season_closed`).

### 1.4 Hot-Seat Privacy Rules, Two-Pass Sub-Turns, and Hand-Off Curtain

Per-seat visibility follows [`docs/design-v2.md`](design-v2.md#L104-L112) (`2026-11-16` Director ruling):

- **Public on every seat's screen:** All seats' free balances, `cred_debt`, `credit_tier`, all resting DEX offers (open and cartel domains), open checks/escrows/pledges, offices, charters, active shocks, announced `ShockForecastEvent`s, and past `SweepReceipt`s / `fill_log`.
- **Private to Seat `i` only:** Seat `i`'s `MandateReveal` (`PrivateMandate` + `RevealSalt`), Seat `i`'s `OracleAuditor` private hint (`hint_turn <= turn < forecast_turn`, `engine.rs:545-562`), Seat `i`'s incoming/sent whispers and personal scratch notes, and Seat `i`'s uncommitted/unrevealed Phase-2 `SealedOrderBundle` draft and `PreimageSecret`s.

Because Sweep Step 0 (`step0_clear_phase1_offer_batch`, `engine.rs:1728-1941`) eliminates continuous price-time priority and matches all Phase-1 `CredOffer`s simultaneously using price priority plus beacon tie-breaks (`engine.rs:1776-1833`), hot-seat keyboard order confers zero arrival-order sniping advantage. Each turn proceeds in beacon/round-rotated seat order (`(turn - 1 + offset) % N`) across two crisp hot-seat sub-passes:

- **Sub-Pass A (Open Market & Talk):** Each human seat enters Phase-1 `MarketAction`s, reads/sends whispers, and prepares a preliminary Phase-2 draft; `ClubBot` seats execute their Pass-A `MarketAction`s once human Pass A completes (or upfront per turn so resting bot depth is visible to humans—see §6 Question 4).
- **Cancel Lock & Sub-Pass B (Post-Lock Check & Sealed Lock):** The host calls `TurnEngine::begin_cancel_lock()` (`engine.rs:602-612`). Each human seat gets a quick post-lock pass (`CancelOffer` refused with `EngineError::CancelLocked`, `engine.rs:634-636`, while buying/importing remains open) to react to resting depth and finalize its Phase-2 `SealedOrderBundle`.
- **Single Local Seal-and-Sweep:** Once every human seat locks Sub-Pass B (and `ClubBot` bundles are collected), the local host executes `advance_to_commit()` (`engine.rs:819`), `submit_order_commitment` (`engine.rs:831`), `advance_to_reveal()` (`engine.rs:855`), `submit_order_reveal` (`engine.rs:870`), and `sweep_turn_with_eval_vrf(&proof)` (`engine.rs:1090`), automatically handling Phase-2 cryptographic commit-reveal under the hood so humans never copy-paste hex hashes or salts.
- **Anti-Holdout Masking & Regent Expiry:** In timed hot-seat play, individual seat commit-lock timestamps and calculation counts stay masked until the pass closes, preventing holdout sniping (informed by PlayDiplomacy Etiquette Guide observations in `2026-11-16-33-idle-seat-takeover-REPORT.md:392`, unchecked at source). If a human seat's turn timer expires without locking a bundle, no Phase-2 commitment is submitted, triggering `league-core`'s built-in Standing Regent (`synthesize_regent_bundle`, `engine.rs:2113-2188`) and converting `SeatIdentity::Human -> AiSyndicate` on `3` consecutive misses or `3` zero-production idle turns (`IDLE_MISS_TAKEOVER_TURNS = 3` at `types.rs:129`, `engine.rs:2120-2125, 3342-3375`).

**Hand-Off Curtain Protocol:** Pressing `Lock & Hand Off` (or emergency `Ctrl-L` screen hide) immediately: (1) drops the outgoing seat's `SeatObservation` struct from active TUI state and resets cursor/input buffers, (2) paints a full-frame **Curtain Interstitial** inside `EnterAlternateScreen` (leaving zero private lines in terminal scrollback history) showing only `TableId`, `Turn t`, sub-pass label, and `"Hand keyboard to Seat k (<Guild Name>)"`, and (3) blocks rendering Seat `k`'s private drawer until a deliberate two-key confirmation `[Space] + [Enter]` (plus Seat `k`'s PIN if configured in Lobby).

### 1.5 Simple Bot Seats (`ClubBot` — Deterministic Rules-Only)

At `ed872e53`, no play-capable rules bot exists in `crates/*/src/`. `TurnEngine::synthesize_regent_bundle` (`engine.rs:2137-2188`) is a private passive custodian that submits zero Phase-1 `MarketAction`s, posts zero quotes, and burns zero projects (`crates/league-core/tests/wave1_rules.rs:1254-1255` notes that real bots await `TrackerBot` / `OpportunistBot`).

`ClubBot` fills non-human seats in Club Mode as a pure-Rust deterministic heuristic (`TrackerBot`-tier baseline, [`docs/design-v2.md`](design-v2.md#L290-L298)) requiring zero LLM, zero Python, and zero network calls. It receives **only** `(obs: &SeatObservation, own_mandate: &PrivateMandate, bot_tie_seed: u64)`—never `&EngineState`, never peer reveals/commitments, and never `SealedEvalSeed`. Adapting the custodial priority order discussed in `2026-11-16-33-idle-seat-takeover-REPORT.md:243-249` (references therein unchecked at source), `ClubBot` evaluates six strict ordered steps each turn:

1. **Cash due checks & pare down high-rate debt:** Collect eligible `CheckCash` IDs (`destination == self` and drawer holds free `CRED` or good cover); allocate free `CRED` above a `1.5x` `[target]` next-turn upkeep reserve to `debt_repayment_cred` when `cred_debt > 0`.
2. **Secure chiral upkeep first (`UpkeepAndDebt`, `predicates.rs:43-58`):** Inspect `shortfall_units` and `held_on_own_resting_sells`. Cancel own resting sell offers on `upkeep_good` before cancel-lock if needed to eliminate avoidable shortfall; bid for `shortfall_units` on the open/eligible cartel book up to `< town_import_premium_bps` (`2.25x` parity, `types.rs:137`); issue `MarketAction::TownImport` only after open market bids fail to cover shortfall and projected `CreditTier` interest/downgrade loss exceeds the `2.25x` import premium.
3. **Operate workshops & procure foreign `Raw` inputs (`SpoilageAndConversion`, `predicates.rs:77-95`):** Score each [`ConverterRecipe`](../crates/league-core/src/types.rs#L485-L498) against `FundamentalParities` (`scoring.rs:20-95`) and `open_book_tariff_bps` (`GoodScarcity`, `predicates.rs:99-121`). Bid up to net-positive margin for scarce foreign `Raw(g)` inputs and schedule `ConverterRunOrder` up to `batches_covered_by_inputs.min(capacity_runs_left)` (`predicates.rs:62-73`), ensuring active production avoids unintentional C1a idle triggers (`engine.rs:114`).
4. **Quote perishable `Raw(seat)` & surplus `Refined(seat)`:** Post `OfferSide::Sell` quotes on own perishable raw stock above secondary-recipe reserve (reducing Step-6 perishable spoilage exposure, `docs/design-v2.md:360`, `types.rs:532-533`) and on refined stock above upkeep + project buffers at `parity * (1 + target_spread_bps + tariff_bps)` `[target]`, narrowing spreads when `spoil_units_total` or closing proximity (`turns_until_latest_close`, `predicates.rs:182`) rises.
5. **Projects, mandates & politics:** Submit `ProjectDeliveryOrder` batches when `ProjectCover.batches_covered > 0` (`predicates.rs:165-172`) and liquidity buffer holds, biasing toward own `MandateKind` (`MinProjectEquity`, `MinRefinedVariety`, `MaintainCleanCredit`, `MinActivePartners`, `commit.rs:330-353`). On Turn `4n`, vote for the `StandForOffice` platform minimizing tariff burden on needed inputs; on Turn `6n`, place conservative `charter_bids` from excess free `CRED`.
6. **Pre-commit preview verification:** Pass candidate `(market_actions, bundle)` through `preview_what_if` (§2, empty peer assumptions); prune any action returned in `refused_market_actions` or causing an avoidable upkeep shortfall while holding stock (`held_enough_but_short_turns == []`, `predicates.rs:755-759`).

### 1.6 Save / Resume and Portable Replay Export

`TurnEngine` (`engine.rs:445-446`), `EngineState` (`engine.rs:120-121`), `RingTable`, `LoggedTurn` (`replay.rs:468-469`), and `SealedMandateDeal` (`commit.rs:577`) already implement `Serialize + Deserialize`. Because [`SealedEvalSeed`](../crates/league-core/src/commit.rs#L1253) intentionally omits `Serialize`/`Deserialize` so state dumps cannot leak it, Club Mode saves wrap local state in a dedicated **`ClubSaveEnvelope`** (`schema_version: u32 = 1`) written atomically (`<save-dir>/club-<table_id>.json.tmp` -> `flush` -> `sync_all` -> rename):

- *Public & Engine state:* `RingTable` (clear `dev` seed), `TurnEngine`, completed `Vec<LoggedTurn>`, current turn sub-pass (`PassA` | `PassB`), pending Sub-Pass `B` locked bundles awaiting final reveal/Sweep, `ClubBot` tie seed, and display preference (`CommodityCatalog` vs plain codes).
- *Isolated host-secrets sub-object (never read by seat UI views):* 32-byte raw VRF seed (rehydrated via `SealedEvalSeed::try_from_bytes`, `commit.rs:1269-1276`), `SealedMandateDeal`, and per-seat local whispers/notes.

`league-tui` auto-saves after every Sweep and every hot-seat keyboard lock (`Ctrl-S` triggers manual save anytime), resumes via `league-tui --resume <path>`, and writes a standard [`SeasonReplayLog`](../crates/league-core/src/replay.rs#L502-L526) on `TurnPhase::Completed` via [`SeasonReplayLog::from_rig_seed`](../crates/league-core/src/replay.rs#L613-L643) passing [`replay_season_with_state_predicates`](../crates/league-core/src/replay.rs#L792-L803).

### 1.7 End-of-Season Screen

When Step 8 sets `season_closed = true` (`TurnPhase::AwaitingMandateReveal`, `engine.rs:74, 1293-1295`), `league-tui` submits every seat's dealt [`MandateReveal`](../crates/league-core/src/commit.rs#L413-L418) via [`TurnEngine::submit_mandate_reveal`](../crates/league-core/src/engine.rs#L1354-L1396), calls [`TurnEngine::finalize_season`](../crates/league-core/src/engine.rs#L1399-L1408) -> [`FinalScoreboard`](../crates/league-core/src/scoring.rs#L651-L659), and computes [`compute_season_metrics`](../crates/league-core/src/predicates.rs#L811-L830). Four End-of-Season tabs present:

1. **Final Standings:** Ranked [`SeatScoreEntry`](../crates/league-core/src/scoring.rs#L626-L647) table (`total_equity = project_equity + net_asset_equity + mandate_bonus`), closing turn `closed_turn` (`24..=32`), and tie-break flag (`standings_tie_key`, `commit.rs:1031-1041`, `scoring.rs:719-728`).
2. **Unsealed Turn-1 Private Mandates:** Each seat's revealed card (`MandateKind` + `points`), pass/miss status, pre-mandate table median net worth `Med(W(T))` (`scoring.rs:470-481`), and `Formula 3` equity bonus (`250 bps` per point times `max(Med(W), 0.5 * W_0)` via `convert_mandate_points_to_equity_with_floor`, `scoring.rs:507-520`, `types.rs:77-85`).
3. **Close-Marking Breakdown (`2026-11-16` 3-Part Rule):** Per-seat [`HoldingMark`](../crates/league-core/src/predicates.rs#L137-L150) table separating units marked against executable non-self standing bids (`units_marked_by_bids`) from remaining units pooled once at the `50%` base floor (`units_at_floor`, `UNSOLD_EXCESS_PARITY_BPS = 5_000`, `types.rs:90`, `scoring.rs:280-340`).
4. **Solvency, Honor & Season Metrics:** Terminal `credit_tier`, `hard_credit_defaults`, `bond_breaches`, `broken_promises`, `honor_penalties`, [`SeatSeasonMetrics`](../crates/league-core/src/predicates.rs#L688-L702) (`spoiled_units`, `stranded_units_at_close`, `held_enough_but_short_turns`), and exported `SeasonReplayLog` path.

## 2. The What-If Preview (`league-core`, `league-tui`, and AI Seats)

### 2.1 How Predicates and `TurnEngine::preview_bundle*` Compose (Zero Second Rules Engine)

As established in the `2026-11-17` premise check, `league-core` already holds both building blocks:

1. **Static current-position predicates (`predicates.rs`):** [`compute_seat_state_predicates`](../crates/league-core/src/predicates.rs#L625-L642) delegates directly to `engine.rs` and `scoring.rs` helpers (`settle_upkeep`, `raw_yield_at_sweep`, `spoilage_bps_at_sweep`, `batches_covered_by_inputs`, `effective_transfer_tariff_bps`, `close_mark_breakdown`, `seat_close_stock`, `predicates.rs:25-33`) to give exact baseline numbers *before* candidate moves.
2. **Exact Sweep simulator (`engine.rs`):** [`TurnEngine::preview_bundle_with_context`](../crates/league-core/src/engine.rs#L916-L1047) clones the engine and runs [`TurnEngine::apply_market_action`](../crates/league-core/src/engine.rs#L615-L627) followed by `sweep_turn_detailed` (`engine.rs:991`, Steps `0–8`) directly, returning exact Step 0–7 execution outcomes in [`BundlePreview`](../crates/league-core/src/engine.rs#L400-L431).

The unified **`league_core::preview_what_if`** API uses zero duplicate rules code: it computes baseline [`SeatStatePredicates`] on a sanitized `PublicPreviewState`, lowers the caller's counterparty assumptions into synthetic peer `MarketAction`s + `peer_bundles`, executes `TurnEngine`'s own Phase-1 and Step 0–7 Sweep path via `preview_bundle_with_context`, and evaluates [`compute_seat_state_predicates`] again on the post-Step-7 simulated state so players see both post-Sweep holdings/upkeep/spoilage and exact hypothetical close marks under `season_end_and_marks` (`predicates.rs:533-622`).

### 2.2 Three Privacy Leaks Found in `preview_bundle_with_context` at `ed872e53`

Calling [`TurnEngine::preview_bundle_with_context`](../crates/league-core/src/engine.rs#L916-L1047) directly in an adversarial or mixed table leaks hidden information through three exact paths in `ed872e53`:

1. **Unannounced Horizon Shocks (`engine.rs:186, 946, 3782`):** `let mut sim = self.clone();` (`engine.rs:946`) copies `self.state.drawn_shocks` (`engine.rs:186`). On Turn `t == shock.forecast_turn` before Turn `t` sweeps (for instance Turn `4` for the shock drawn on Turn `2` at [`commit.rs`](../crates/league-core/src/commit.rs#L982-L989)), `sim.sweep_turn_detailed` executes `step8_shocks_and_close` (`engine.rs:3782-3788`) and emits that shock inside `BundlePreview.sweep_receipt.public_forecasts` (`engine.rs:270, 430`)—leaking an unannounced `OracleAuditor` shock early to non-Auditor seats.
2. **Peer `Commit`/`Reveal` Buffers (`engine.rs:174-176, 980-987`):** `preview_bundle_with_context` is allowed in `TalkAndMarket | Commit | Reveal` (`engine.rs:928-931`), **yet inserts empty default bundles for unmentioned peers only `if was_talk_and_market`** (`engine.rs:980-987`). If called during `Commit` or `Reveal`, rivals' already-submitted `turn_commits` and plaintext `turn_reveals` remain live inside `sim.state`, exposing unrevealed orders via simulated Sweep outcomes.
3. **Full-State Digest and Step-8 Dummy-Beacon Outputs (`engine.rs:274, 297, 300`):** `BundlePreview.sweep_receipt` exposes `post_state_digest` (`SHA-256` over the unredacted `EngineState`, `engine.rs:534-542`), `newly_drawn_shocks`, `season_closed`, and peers' `pbrs_deltas` (`engine.rs:274-300`).

### 2.3 Isolation Architecture: `PublicPreviewState` (`SeatObservation`)

In Card 2, `preview_what_if` never clones raw `EngineState`; it constructs an isolated `PublicPreviewState` from public state + `seat`'s own permitted view (`TurnEngine::observe_seat(seat)`):

- Retains strictly public fields (`docs/design-v2.md:108`: balances, `cred_debt`, `credit_tier`, resting `offers`, active `checks`, `escrows`, `dual_escrows`, `pledges`, `domains`, `council_platforms`, `charters`, `active_shocks`, `cancel_locked`, `fill_log`, `delivery_ledger`, `TableSpec` with `dealt_mandate_commits` scrubbed).
- Filters `drawn_shocks` strictly to already publicly forecast shocks (`shock.forecast_turn < state.turn`, since `forecast_turn == state.turn` only posts publicly at the *end* of Turn `state.turn`'s Sweep) plus `OracleAuditor` private hints (`hint_turn <= state.turn < forecast_turn`) **only** when `seat` holds active [`CharterRole::OracleAuditor`](../crates/league-core/src/types.rs#L437).
- Zeroes `turn_commits`, `turn_reveals`, `mandate_commits`, and `mandate_reveals`, and fills every unmentioned peer with `SealedOrderBundle::default()` across **all** pre-Sweep phases (`TalkAndMarket | Commit | Reveal`).
- Uses fixed public neutral tie-break beacon `PREVIEW_NEUTRAL_BEACON = derive_turn_beacon(0, table_id, Turn(turn))` (`engine.rs:910`) by default (with an optional pessimistic tie mode for Step-0 batch fills), and suppresses Step-8 shock draws and closing-bell rolls in the simulation (reporting Steps 0–7 outcomes cleanly plus Turn-`t` active shocks that were already activated at start of Turn `t`, `engine.rs:519, 1297`).

### 2.4 Inputs, Outputs, and Secret-Exclusion Contract

- **Inputs (`WhatIfRequest`):**
  - `seat: Seat`
  - `market_actions: Vec<MarketAction>` (candidate Phase-1 actions when `phase == TalkAndMarket`)
  - `bundle: SealedOrderBundle` (candidate Phase-2 orders)
  - `assumptions: CounterpartyAssumptions` (user- or AI-toggled hypotheses lowered cleanly into synthetic peer `MarketAction`s and `peer_bundles`):
    1. `assumed_cancelled_offer_ids: Vec<u64>` (model a peer pulling a resting offer before Sweep when `!cancel_locked`; ignored when `cancel_locked == true`).
    2. `assumed_peer_market_actions: Vec<MarketAction>` (model hypothetical crossing bids/asks or `TownImport`).
    3. `assumed_cosigned_swaps: Vec<AtomicSwapProposal>` and `assumed_cosigned_dual_escrows: Vec<DualEscrowProposal>` (model counterparty matching co-signatures in `peer_bundles`).
    4. `assumed_peer_deliveries: Vec<(u8, ContractDeliveryOrder)>` and `assumed_peer_escrow_finishes: Vec<(u8, EscrowFinishUnlock)>` (test bond/DvP delivery or `PREIMAGE-SHA-256` unlock outcomes).
    5. `assumed_bounced_check_ids: Vec<u64>` (test drawer illiquidity prior to Step 3 so receivable `CheckPreviewOutcome::Bounced` risk appears immediately).
    6. `tie_mode: BatchTiePreviewMode` (`NeutralSeed` default, or `PessimisticForSeat` placing `seat` last in Step-0 equal-price batch ties).
- **Outputs (`WhatIfPreview`):**
  - `baseline_predicates: SeatStatePredicates` and `post_sweep_predicates: SeatStatePredicates` (exact before/after upkeep, spoilage, scarcity, and hypothetical close-mark `HoldingMark`s explicitly labeled *"Hypothetical close mark after Steps 0–7; assumes open season and no unforecast shock"*).

### 2.5 Proving Exact Equality with `TurnEngine`

1. **Single-codepath construction:** `preview_what_if` executes `TurnEngine::apply_market_action` and Steps `0–7` of `TurnEngine::sweep_turn_detailed` directly. Because [`draw_shocks_for_turn`](../crates/league-core/src/commit.rs#L982-L989) schedules every shock strictly as `hint_turn = draw + 1`, `forecast_turn = draw + 2`, `realize_turn = draw + 3`, any shock active in Turn `t`'s Steps `0–7` was already publicly realized into `state.active_shocks` at the end of Turn `t - 1` (`engine.rs:1297, 3725-3748`), so zero hidden shock state ever affects Steps `0–7` of Turn `t`.
2. **Step 0–7 Replay Equivalence Property (`proptest` gate in Card 2):** Across random `dev`-pool tables and multi-turn `SeasonReplayLog` trajectories, feeding `preview_what_if` a turn's actual Phase-1 actions, actual revealed `peer_bundles`, and actual `turn_beacon` (matching Step-0 tie order) asserts bit-for-bit equality (`assert_eq!`) between `preview.post_sweep_seat_state`, `preview.upkeep`, `preview.spoilage.total`, and all Step 0–7 order outcomes and the live `TurnEngine::sweep_turn*` state after Step 7.
3. **Secret Non-Interference Property (`proptest` gate in Card 2):** Generating twin engines `E1`, `E2` with identical public state for `seat` while arbitrarily mutating rival `turn_commits`/`turn_reveals`, `mandate_commits`/`mandate_reveals`, `eval_vrf_pubkey`, and unannounced `drawn_shocks` (`forecast_turn >= turn`) asserts `assert_eq!(preview_what_if(&E1.observe_seat(s), req), preview_what_if(&E2.observe_seat(s), req))`.

### 2.6 Giving AI Seats the Exact Same Tool (`league-relay`)

Today [`ChatCompletionRequestWire`](../crates/league-relay/src/relay.rs#L2499-L2516) supports zero tool calls and `crates/league-relay` has zero dependency on `league-core` ([`crates/league-relay/Cargo.toml`](../crates/league-relay/Cargo.toml#L19-L28)). Wave 2 exposes the exact same `league_core::preview_what_if` binary function to AI seats in `league-relay`:

- The turn driver places `to-seat/day-DD-act-<Guild>.preview-state.json` containing strictly serialized `PublicPreviewState` for `<Guild>` (the relay process never reads other seats' files or hidden secrets).
- CLI option `--preview-tool <off|on>` (default `off` for backward comparability with `v2_neutral_2026_11_15_r6`; pinned in `<game-dir>/relay/setup.json`, [`GameSetupRecord`](../crates/league-relay/src/relay.rs#L2111-L2139)) adds one OpenAI-format tool `preview_turn_orders` on `round == act`, executing a bounded tool-call loop (`max_preview_calls_per_turn = 3` `[target]`) where every HTTP model round-trip still consumes and checks the existing `try_reserve` credit/GPU-second cap before network dispatch. Because adding a tool alters AI output distributions, `--preview-tool on` activates its own wording arm (§8).
